Search Relevance Rater

Rate each result for one query on a 0 to 4 scale, then move results up and down to see how the ranking metrics react. DCG rewards putting good results first, and NDCG compares your order with the best possible order for the same ratings. This is the same kind of judgment used in search quality evaluation. Everything runs in your browser.

4Perfect: fully answers the need
3Excellent: very helpful
2Good: useful, some gaps
1Fair: marginal value
0Bad: off-topic or harmful
